## Status vocabulary

- `standalone-test-passed`: an executable non-Android verification passed in the delivery environment.
- `partially-verified`: source/state verification passed, but Android Gradle or runtime gates remain open.
- `test-defined-not-executed`: automated test exists but could not run in this environment.
- `configured-not-executed`: Gradle/CI configuration exists; publication or consumer build still requires external execution.
- `build-verification-required`: Android compilation is required before the requirement can be accepted.
- `statically-reviewed`: checked from source and distribution structure only.

The machine-readable source of truth is `release/requirements-traceability.json`.
